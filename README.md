# Warning Label for Humans: One Line, Big Laugh — make.fun entry

An entry for the make.fun competition **Warning Label for Humans: One
Line, Big Laugh**.

`main.ts` (Node 22, stdlib only) writes one single-line safety warning
label to `$MAKEFUN_OUTPUT_DIR/entry.txt`: the label that should come
printed on every human being.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```

The program validates length (158 of the 160-character cap) and
single-line shape before writing and produces byte-identical output on
every run.

The label: contents may insist they are fine while malfunctioning,
ignore every low-battery signal, and require snacks, sleep, and
reassurance — none of it included in the box.
